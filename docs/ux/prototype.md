## 3. 设计决策

1. **完全复用 DSH 既有视觉语言**：颜色绑定主题变量（同名 Color Variables），字号 / 圆角 / 间距与真实对话页一致（tab 13/500 + 2px 下划线 + gap 32；输入卡 radius 28；用户气泡 radius 20 / padding 10×16）。
2. **agent→agent 用正文内联 @**：`@backend 接口清单已确认…`（business-primary 蓝色），不再单独出「→ 发送给」chip 行；用户消息的「已同时发送给 …」用 11px 灰字，无绿勾/底色，与蓝色 @ 提及天然区分。
3. **过程降噪**：工具调用压成一行折叠条（`⌄ 3 个工具调用已折叠 · 过程见「轨迹」视图`），正文流只保留发言。
4. **subagent 从属可视**：与普通消息同形，仅在名字后加 11px 灰字后缀「· ux 的子体」，不引入缩进/连接线/徽标。
5. **折叠遮罩不依赖图片**：16 层 4px 半透明 bg 叠加实现渐变，任意主题下导出正确。
6. **令牌即实现契约**：Figma 变量名 = 前端 CSS 变量名，可直接生成 `var(--dsw-alias-*)`。
